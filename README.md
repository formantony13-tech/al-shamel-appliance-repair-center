# مركز قطب للحل السريع — صيانة الأجهزة المنزلية

موقع عربي لإدارة طلبات الصيانة ومعرض الأعمال وسوق الأجهزة لمركز قطب للحل السريع في **محافظة البحيرة**. مبني باستخدام React وTypeScript وVite وFirebase.

## التطوير والتحقق

```bash
npm install
npm run dev
npm run lint
npm run build
```

لا يوجد حاليًا مسار اختبار آلي شامل أو اختبار طرف إلى طرف في `package.json`. نجاح `lint` و`build` يتحقق من الأنواع وتجميع الإنتاج، لكنه لا يختبر تسجيل الدخول أو صلاحيات Firebase أو رفع الصور فعليًا.

## الإدارة

مدخل الإدارة غير ظاهر في روابط الزوار. يفتح المشرف المصرح له المسار `/#/admin` ثم يسجل الدخول بحساب Firebase موثق ومدرج في صلاحيات الإدارة. صلاحية الواجهة وحدها لا تكفي؛ يجب أن تسمح قواعد Firebase المنشورة بالعملية المطلوبة.

## الحجوزات والخصوصية

تُحفظ بيانات الحجز الكاملة في مجموعة خاصة بالمشرفين. سجل المتابعة العام لا يتضمن الاسم أو الهاتف أو العنوان، ويُستعلم عنه باستخدام رمز عشوائي طويل يعمل كمفتاح خاص. الرموز القديمة ذات الصيغة القصيرة مرفوضة من القراءة العامة في قواعد Firestore الموجودة بالمستودع. يجب نشر القواعد المطابقة للشيفرة كي ينطبق ذلك على بيئة الإنتاج.

## الصور والمخزون

تستخدم معالجة الصور ضغطًا محليًا قبل الرفع إلى Firebase Storage. صور الحجوزات خاصة، بينما صور الأعمال والأجهزة العامة مخصصة للقراءة العامة ولرفع المشرفين فقط وفق قواعد Storage. تُدار عناصر سوق الأجهزة من لوحة الإدارة، ولا ينبغي وضع مخزون تجريبي أو صور غير حقيقية على أنها معروضات فعلية.

## النشر

النسخة الحالية منشورة على GitHub Pages. يتطلب نشر تغييرات الموقع تحديث فرع النشر وفق إعداد المستودع. تغييرات `firestore.rules` و`storage.rules` لا تُنشر تلقائيًا مع صفحات GitHub؛ يجب نشرها إلى Firebase بطريقة مستقلة والتحقق من نجاحها قبل اعتماد وظائف الإنتاج.
